# 13 SYSTEM

Portfolio of Urfan Zeynalov (13). An invented retro console: pick a project on the select screen and play a short game that shows how it works.

## Run it

```bash
npm install
npm run dev        # local dev server
npm run build      # production build into dist/
```

Pushing to `main` builds and deploys to GitHub Pages (`.github/workflows/deploy.yml`). The workflow sets the base path from the repo name.

## Where things live

| What | File |
|---|---|
| Projects, components, status, game per project | `src/data/projects.js` |
| Name, links, email, skills inventory | `src/data/site.js` |
| Page templates (home, about, case studies, 404) | `src/pages/templates.js` |
| Build log posts (Markdown) | `content/log/*.md` |
| Games (one module each, lazy-loaded) | `src/games/*.js` |
| Console (boot, select, loader, input, sound) | `src/console/` |
| CV download | put your file at `public/cv.pdf` |
| Images | `public/assets/` |

HTML pages are generated by `scripts/gen-pages.js` before every dev/build run. Edit the sources above, not the HTML.

## Add a new game

1. Copy `src/games/pwm.js` to `src/games/<id>.js` and change it. A game exports `{ id, title, goal, controls, learned, create(api) }`. `create` returns `{ update(dt), draw(ctx) }` and calls `api.end({ win, score, headline })` when the round ends.
2. Add or edit the project in `src/data/projects.js` with `game: '<id>'` and a status other than `'locked'`.
3. Optional: add a 64×64 portrait at `public/assets/portraits/<id>.png`.
